# Throw a Dart Art Direction Handoff

Throw a Dart inherits the shared Throw A Way Games visual rules defined in the master repository, especially the dedicated marquee and edit-discipline standards.

## What to carry forward

- Main gameplay art targets 128×128.
- Lower physical screen remains 64×32 and follows the shared UI standard.
- Final individual game/stage art is **theme-first**.
- Marquees are **1:1 cinematic box art**, not screenshots of the gameplay board.
- The title should be huge, readable, theme-matched, and balanced within the composition.
- Marquee art should push action, humor, forced perspective, close-ups, Dutch angles, and dramatic depth when appropriate.
- A marquee should tell the ridiculous story behind the game rather than simply redraw the playfield.
- Once an image is approved, future edits should be surgical. Change only the requested element.
- Alternate gameplay states must preserve exact target centers and geometry whenever possible.
- New prompts must be reset to the active game/stage only so imagery from the previous game does not contaminate the next one.

## Current Throw a Dart phase

The current Bullseye Big Top Circus build is still a mechanics vertical slice. Temporary act names and art can remain scaffolding while target size, movement, hit forgiveness, multiplayer flow, and cabinet behavior are tested.

Once a mechanic is approved:

1. design the final stage fantasy,
2. lock the gameplay board and target geometry,
3. create alternate target/result states in-place,
4. create a separate 1:1 marquee/key-art image,
5. preserve the approved composition during revisions.

## Creative target

Throw a Dart should feel like it belongs beside Throw a Strike and Throw a Ball, but it does not need to copy their themes. Shared DNA comes from UI, player colors, readable target hierarchy, THROW READY, event rhythm, and cabinet polish. The art itself should be free to become circus, board-game, pinball, poker, battleship, bingo, or other dedicated worlds as each mode is developed.

## Marquee reminder

When a mode gets final marquee art, ask:

**What is the ridiculous movie poster hidden inside this game?**

That image should be more dynamic than the gameplay board and still read clearly at 128×128.
